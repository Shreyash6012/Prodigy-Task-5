# 🌐 Web Scraping Project

## 📌 Task-05 | Prodigy Infotech

This project is part of **Task-05** completed during my internship at **Prodigy Infotech**.  
The objective of this task is to build a **Web Scraping program** that extracts product information from an e-commerce website and stores the data in a structured format.

---

## 📝 Description

The Web Scraping program extracts **product details such as name, price, and rating** from an online e-commerce website.  
The extracted data is processed and stored in a **CSV file**, making it easy to analyze or reuse for further applications.

The project demonstrates the practical use of web scraping techniques and data handling in real-world scenarios.

---

## ⚙️ Features

- Scrapes product details from an e-commerce website
- Extracts:
  - Product Name
  - Price
  - Rating
- Stores data in a structured **CSV file**
- Clean and readable data output
- Beginner-friendly implementation

---

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV file handling

---

## 🔄 How the Program Works

1. Sends a request to the target website.
2. Parses the HTML content using BeautifulSoup.
3. Extracts required product information.
4. Stores the scraped data into a CSV file.
5. Displays confirmation after successful execution.
